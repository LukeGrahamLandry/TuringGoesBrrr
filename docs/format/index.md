# Circuit Schematic File Formats

A logic circuit is a collection of components (which have inputs and outputs) and wires which connect them. There are many different file formats used to save these structures. [TuringGoesBrrr](/circuit) is an online tool that allows viewing circuits and converting between many file formats.

## File Format Documentation

- [Logisim (.circ)](/format/logisim)
- [Turing Complete game saves](/format/turing-complete)
- [Minecraft Redstone](/format/redstone)

## TuringGoesBrrr Format Support 

```
| **Feature**         | Turing Complete | Logisim | Minecraft | Verilog   |
|---------------------|-----------------|---------|-----------|-----------|
| Import              | YES             | YES     | NO        | WIP       |
| Export              | WIP             | WIP     | WIP       | WIP       |
| Component Positions | YES             | YES     | YES       | NO        |
```
